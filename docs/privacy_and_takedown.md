# Privacy, Contact, and Takedown

## Public project identity

The public maintainer is `kobekkoo`.

A public legal name or personal email address is not required for the GitHub repository, Hugging Face Dataset Card, or `CITATION.cff`. The collector’s legal identity should still appear in private participant consent records.

## Public support

- General questions: GitHub Discussions
- Reproducible bugs and non-sensitive data-quality reports: GitHub Issues

These channels are public. Do not include personal details, raw consent records, or sensitive participant information.

## Confidential requests

For participant identity, consent, privacy, withdrawal, or takedown requests, email **[kobekko94@gmail.com](mailto:kobekko94@gmail.com)**.

Do not submit confidential information through GitHub Issues or Discussions. GitHub’s standard collaboration features are public and are not a private person-to-person messaging channel.

## Takedown process

When a valid participant request is received:

1. Verify the request privately using the minimum information necessary.
2. Identify all `speaker_id` and `sample_id` records belonging to the participant.
3. Disable new access while investigating when appropriate.
4. Remove affected files from the next dataset revision.
5. Publish a non-identifying changelog entry.
6. Notify previously approved users that the listed sample IDs should be deleted.
7. Preserve private documentation of the request and response.
8. Do not publish the participant’s identity or reason for removal.

## Limits

A public or gated release cannot guarantee complete deletion from copies already downloaded. This limitation must be disclosed during consent.
