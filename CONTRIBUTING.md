# Contributing

This repository accepts contributions to documentation, validation scripts, benchmark methodology, and data-quality reports.

The raw audio dataset is manually gated and should not be attached to GitHub issues or pull requests.

## Before opening an issue

- Remove personal information.
- Do not quote or attach raw participant audio.
- Include the dataset version and `sample_id` where relevant.
- For a transcript correction, provide only the minimum text needed to explain the issue.

## Public channels

- Use **GitHub Discussions** for general methodology questions.
- Use **GitHub Issues** for reproducible code bugs and non-sensitive data-quality reports.

## Confidential reports

Do not use a public issue for participant identity, consent, privacy, or takedown requests. Email [kobekko94@gmail.com](mailto:kobekko94@gmail.com), as listed in `docs/privacy_and_takedown.md`.

## Pull requests

1. Create a focused branch.
2. Add or update tests where practical.
3. Run the validation scripts.
4. Explain any schema or scoring changes.
5. Do not add raw audio unless the maintainer explicitly requests it through an approved private workflow.
